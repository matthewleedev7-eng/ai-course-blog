## 📌 ¿De qué trata este curso?
El **Generative AI Learning Plan for Developers** de Amazon Web Services es la ruta de certificación oficial diseñada para ingenieros que construyen aplicaciones en la infraestructura cloud de AWS.

El programa profundiza en el uso de **Amazon Bedrock**, la plataforma administrada que permite acceder a modelos fundacionales líderes (Anthropic Claude, Meta Llama, Amazon Titan) a través de una API unificada y segura. Aprenderás a orquestar agentes autónomos, implementar RAG con bases de datos vectoriales en AWS y proteger la privacidad de datos corporativos.

---

## 🎯 ¿A quién está dirigido?
- Arquitectos de soluciones y desarrolladores cloud que trabajan con el ecosistema AWS.
- Empresas que buscan integrar modelos de IA generativa cumpliendo estrictos estándares de seguridad y gobernanza.
- Profesionales que desean obtener insignias oficiales de habilidades de AWS Skill Builder.

---

## 📚 Plan de Estudios Principal
1. **Fundamentos de Amazon Bedrock**: Configuración de acceso a modelos y pruebas interactivas en la consola.
2. **Ingeniería de Prompts y APIs Unificadas**: Control programático de inferencia con el SDK de AWS (Boto3).
3. **Agentes y Conexión con Bases de Conocimiento (Knowledge Bases)**: Conexión de LLMs con fuentes de datos corporativas para sistemas RAG.
4. **Seguridad y Bedrock Guardrails**: Filtrado de respuestas y protección frente a inyecciones de prompts.
5. **Evaluación de Modelos**: Métricas objetivas para seleccionar el modelo óptimo según costo y latencia.
