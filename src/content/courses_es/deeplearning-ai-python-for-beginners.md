## 📌 ¿De qué trata este curso?
Creado por la leyenda del aprendizaje automático, el **profesor Andrew Ng**, **AI Python for Beginners** es el curso de iniciación de DeepLearning.AI diseñado específicamente para principiantes y personas sin experiencia previa en programación.

A diferencia de los cursos tradicionales centrados en memorizar sintaxis abstracta, este curso integra la IA generativa directamente en tu proceso de aprendizaje. Utilizando un entorno Jupyter Notebook interactivo en el navegador y sin necesidad de instalación local, aprenderás **variables, bucles, funciones y estructuras de datos en Python mientras construyes herramientas de automatización y consultas a modelos de lenguaje (LLM)**.

---

## 🎯 ¿A quién está dirigido?
- Profesionales de negocios y personas sin formación técnica que desean aprender a programar utilizando flujos de trabajo modernos con IA.
- Principiantes que aprecian el estilo pedagógico claro, intuitivo y cercano del profesor Andrew Ng.
- Cualquier persona que busque una introducción práctica y rápida a Python en menos de 4 horas.

---

## 📚 Plan de Estudios Principal
1. **Primeros Pasos con Python e IA**: Variables, tipos de datos y lógica condicional asistida por prompts.
2. **Bucles y Control de Flujo**: Estructuración de lógica iterativa para automatizar tareas repetitivas.
3. **Listas y Diccionarios**: Procesamiento y análisis de texto no estructurado y respuestas JSON.
4. **Llamadas Prácticas a APIs de LLM**: Conexión de scripts en Python con modelos de OpenAI y Anthropic.
5. **Proyecto de Automatización**: Creación de un script que resume informes y clasifica datos de forma autónoma.
