### 📖 이 오픈북이 특별한 이유

1. **상업적 API 종속 탈피**:
   - OpenAI나 Anthropic API 과금 없이, 일반 노트북이나 데스크톱 GPU에서 Hermes 3를 구동하는 방법을 스텝 바이 스텝으로 안내합니다.
2. **단순 대화를 넘어선 '에이전트 기능' 집중**:
   - Hermes 3의 최대 장점인 **JSON 모드와 도구 호출(Tool Use)**을 파이썬 코드로 직접 구현해 볼 수 있습니다.
3. **위키독스 무료 열람**:
   - 별도 결제나 가입 없이 웹 브라우저에서 바로 실습 코드를 복사하여 실행할 수 있습니다.
