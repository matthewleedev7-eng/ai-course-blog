## 📌 What is this course?
Designed by **Amazon Web Services (AWS)** for cloud software engineers and solutions architects, the **Generative AI Learning Plan for Developers** is the premier free training curriculum for building enterprise AI applications in the cloud.

Hosted on **AWS Skill Builder**, this 100% free learning plan covers the full production lifecycle—from foundational model concepts to integrating **Amazon Bedrock (calling Claude 3.5, Llama 3, Titan via a unified API), chaining prompts with LangChain, building robust Retrieval-Augmented Generation (RAG) pipelines with OpenSearch, and implementing security guardrails**.

Completion grants an official digital badge verifiable on Credly and LinkedIn.

- Backend developers and cloud architects building scalable generative AI applications on AWS infrastructure.

## 📚 Core Syllabus
1. **Introduction to Generative AI - Art of the Possible**: Foundation models, business value, generative capabilities
2. **Planning a Generative AI Project**: Scoping feasibility, cost estimation, model evaluation metrics
3. **Amazon Bedrock Getting Started**: Accessing frontier models through unified API endpoints
4. **Prompt Engineering Basics in Bedrock**: Optimizing system prompts and parameter controls in cloud consoles
5. **Building Generative AI Applications with LangChain**: Orchestrating multi-step agentic workflows
6. **Retrieval Augmented Generation (RAG) on AWS**: Implementing vector databases with Amazon OpenSearch
7. **Security, Privacy, and Responsible AI**: Guardrails for Bedrock, data isolation, and hallucination suppression
