## 📌 What is this course?
Created by **Anthropic's Developer Relations team**, this interactive course is the gold standard for mastering prompt engineering with **Claude 3.5 Sonnet** and the Claude model family.

Instead of vague advice, it is hosted entirely inside interactive Jupyter/Colab notebooks where you execute live API calls and observe the exact impact of **XML tagging (`<instructions>`, `<context>`), system role assignment, and chain-of-thought elicitation**.

---

## 🎯 Who is this for?
- Developers and prompt engineers who want Claude to follow complex multi-step rules without drifting.
- Builders leveraging Claude's large 200k context window for long-document analysis.
- Teams designing production-grade prompts with deterministic formatting (JSON/XML).

---

## 📚 Course Curriculum
1. **Chapter 1: Being Clear and Direct**: Removing ambiguity and defining explicit output schemas.
2. **Chapter 2: The Power of XML Tags**: Separating input data from executable instructions.
3. **Chapter 3: System Roles & Personas**: Directing tone, domain expertise, and guardrails.
4. **Chapter 4: Few-Shot Examples**: Guiding style and edge-case handling through examples.
5. **Chapter 5: Chain of Thought (CoT)**: Forcing step-by-step reasoning for logic-heavy tasks.
6. **Chapter 6: Complex Logic & Edge Cases**: Formulating effective negative constraints.

---

## 💡 Learning Tips
- **One-Click Google Colab**: You can click the "Open in Colab" badge directly on GitHub to run every notebook in your browser without local Python installation.
- **Anthropic Console Workbench**: Use the web-based Workbench tool to iterate on prompts rapidly before committing them to code.
