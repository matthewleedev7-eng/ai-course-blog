## 📌 What is this course?
**Google's Machine Learning Crash Course (MLCC)** is the legendary curriculum originally developed by Google's top AI researchers to train internal software engineers into machine learning practitioners. It is now open to the global developer community free of charge.

Rather than getting bogged down in complex pencil-and-paper derivations, students manipulate interactive neural networks directly within the browser using the **TensorFlow Playground**, while testing real-world models via **one-click Google Colab notebooks**.

Featuring short video lessons from Google engineers, practical coding exercises, and comprehensive case studies, MLCC remains the gold-standard foundation for understanding how machine learning algorithms optimize loss in production.

---

## 🎯 Who is this for?
- Developers and STEM students seeking an intuitive, visually grounded foundation in machine learning.
- Programmers with basic Python familiarity looking to understand gradient descent, overfitting, and loss functions.
- Anyone eager to learn how Google engineers design, evaluate, and debug real-world production ML pipelines.

---

## 📚 Core Syllabus
1. **Foundations of ML**: Supervised learning, linear regression, loss functions, and gradient descent
2. **Training Optimization**: Learning rates, regularization, validation sets, and mitigating overfitting
3. **Classification & Logistic Regression**: Decision thresholds, Precision/Recall trade-offs, and ROC-AUC curves
4. **Deep Neural Networks**: Non-linearity activation functions, hidden layers, and backpropagation mechanics
5. **Embeddings**: Representing high-dimensional categorical features in continuous dense vector spaces
6. **Real-World Engineering**: Mitigating data bias, model fairness, and production ML best practices
