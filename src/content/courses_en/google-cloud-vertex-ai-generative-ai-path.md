## 📌 What is this course?
Hosted on **Google Cloud Skills Boost**, the **Vertex AI & Generative AI for Developers Learning Path** is Google Cloud's premier production track for engineers building scalable enterprise AI applications.

Rather than remaining in passive theory, students access **free Google Cloud sandbox environments to directly configure production tools inside Vertex AI Studio**. You will connect frontier **Gemini 1.5 Pro and Flash models via Python SDK, design multimodal prompts, integrate JSON Schema function calling, and construct production-ready Retrieval-Augmented Generation (RAG) pipelines backed by Vertex AI Vector Search**.

Completing all hands-on labs and passing the timed assessment lab awards an **official, verifiable Google Cloud digital skill badge** directly shareable on LinkedIn and Credly.

- Software developers architecting production generative AI applications on Google Cloud infrastructure.

## 📚 Core Syllabus
1. **Introduction to Vertex AI Studio**: Zero-shot and few-shot prompt engineering on Gemini via console UI
2. **Python SDK Integration**: Programmatic model invocation for text, image, audio, and video multimodal payloads
3. **Structured Outputs & Function Calling**: Enforcing JSON response schemas and connecting external APIs
4. **Vertex AI Vector Search & RAG**: Transforming internal documents into embeddings and creating low-latency search indices
5. **Responsible AI & Safety Filters**: Customizing threshold parameters for hate speech, harassment, and dangerous content
6. **Challenge Lab & Credentialing**: Complete a live timed capstone project to earn the official Google Cloud Skill Badge
