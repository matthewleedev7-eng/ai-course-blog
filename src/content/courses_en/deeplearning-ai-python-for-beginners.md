## 📌 What is this course?
Created by legendary machine learning pioneer **Professor Andrew Ng**, **AI Python for Beginners** is DeepLearning.AI's flagship introductory curriculum designed specifically for newcomers and non-programmers.

Unlike traditional courses focused on dry syntax memorization, this course embeds generative AI directly into your learning flow. Using an interactive in-browser Jupyter notebook environment with zero setup, you learn **Python variables, control flow, functions, and data structures while actively building AI-powered automation scripts and calling frontier LLM APIs**.
