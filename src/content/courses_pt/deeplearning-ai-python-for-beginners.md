## 📌 Sobre o que é este curso?
Desenvolvido pelo lendário professor e pioneiro em aprendizado de máquina, **Andrew Ng**, **AI Python for Beginners** é o curso de introdução da DeepLearning.AI criado especificamente para quem nunca programou antes.

Em vez de focar apenas na memorização de sintaxe árida, o curso integra a IA generativa ao processo de aprendizado. Utilizando cadernos Jupyter interativos no navegador (sem necessidade de instalação local), você aprenderá **variáveis, loops, funções e estruturas de dados em Python enquanto constrói ferramentas de automação e integra chamadas a modelos de linguagem (LLMs)**.

---

## 🎯 Para quem é recomendado?
- Profissionais e estudantes sem formação técnica que desejam aprender a programar usando fluxos modernos com IA.
- Iniciantes que apreciam a metodologia didática e acolhedora do professor Andrew Ng.
- Qualquer pessoa que queira uma introdução prática e rápida a Python em menos de 4 horas.

## 📚 Conteúdo Programático Principal
1. **Primeiros Passos com Python e IA**: Variáveis, tipos de dados e lógica condicional com apoio de prompts.
2. **Loops e Controle de Fluxo**: Estruturação de código iterativo para automatizar tarefas repetitivas.
3. **Listas e Dicionários**: Processamento e análise de textos não estruturados e respostas em formato JSON.
4. **Chamadas Práticas a APIs de LLM**: Conexão de scripts Python com modelos de ponta da OpenAI e Anthropic.
5. **Projeto Final de Automação**: Criação de um script que resume relatórios e organiza dados automaticamente.
