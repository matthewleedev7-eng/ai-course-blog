## 📌 Sobre o que é este curso?
Desenvolvido pelos próprios engenheiros e pesquisadores da **Hugging Face**, a plataforma de referência global em aprendizado de máquina de código aberto, este curso é considerado a **bíblia prática para engenheiros de NLP e modelos Transformers**.

O programa guia o estudante desde os conceitos de tokenização e arquiteturas encoder-decoder até o **ajuste fino (fine-tuning) de modelos como BERT, GPT e T5** para tarefas de classificação de texto, reconhecimento de entidades nomeadas (NER), tradução e geração de código.

Todos os módulos contam com cadernos executáveis no Google Colab, permitindo que você experimente pipelines de treinamento sem custo de hardware local.

## 🎯 Para quem é recomendado?
- Desenvolvedores com familiaridade em Python e PyTorch que desejam dominar o ecossistema Hugging Face.
- Engenheiros de dados e cientistas de IA que precisam treinar e customizar modelos de linguagem proprietários.
- Qualquer desenvolvedor que queira subir modelos treinados e compartilhá-los no Hugging Face Hub.

## 📚 Conteúdo Programático Principal
1. **O que são Transformers?**: Funcionamento de autoatenção, cabeçalhos de atenção e decodificadores.
2. **Biblioteca 🤗 Transformers**: Uso da API `pipeline` para inferência rápida de modelos pré-treinados.
3. **Ajuste Fino (Fine-Tuning)**: Preparação de dados com a biblioteca `datasets` e treinamento com `Trainer`.
4. **Tokenizadores Avançados**: Criação de tokenizadores WordPiece e BPE (Byte-Pair Encoding) de alto desempenho em Rust.
5. **Treinamento Distribuído**: Aceleração de modelos em múltiplas GPUs com 🤗 `Accelerate`.
6. **Publicação no Hub**: Compartilhamento de pesos, documentação (Model Cards) e demonstrações interativas no Spaces.
