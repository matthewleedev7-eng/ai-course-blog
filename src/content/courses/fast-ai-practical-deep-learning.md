## 📌 어떤 강의인가요?
Kaggle의 전설이자 수많은 AI 연구자들을 배출한 **제레미 하워드(Jeremy Howard)**가 만든 전 세계에서 가장 사랑받는 무료 딥러닝 강의입니다.

일반적인 대학 강의처럼 지루한 미적분, 선형대수학부터 시작하지 않고, **첫 번째 수업 20분 만에 99% 정확도를 가진 이미지 분류 AI 모델을 직접 만들어보는 Top-Down 방식**으로 가르칩니다. 실제로 동작하는 모델을 먼저 만들어보고, 그 안의 원리를 거꾸로 파헤쳐가는 혁신적인 교수법으로 전 세계 수백만 명이 수강했습니다.

---

## 🎯 추천 대상
- 복잡한 수학 공식 때문에 딥러닝 공부를 포기했던 비전공자/개발자
- 최신 컴퓨터 비전, 자연어 처리(NLP), 이미지 생성 모델을 5줄의 파이썬 코드로 구현해보고 싶은 분
- 실무에서 즉시 활용 가능한 모델 훈련 최적화 기법(Learning Rate Finder, Data Augmentation)을 배우고 싶은 분

---

## 📚 주요 커리큘럼
1. **첫 번째 딥러닝 모델 만들기**: 단 몇 줄의 코드로 새와 비행기 구분 모델 학습 및 배포
2. **프로덕션 배포 실습**: Hugging Face Spaces와 Gradio를 사용한 나만의 웹 앱 무료 배포
3. **신경망의 내부 동작 원리**: 확률적 경사하강법(SGD)을 엑셀과 주피터 노트북으로 직관적 이해
4. **자연어 처리(NLP)와 LLM 기초**: 감성 분류기 및 언어 모델 전이 학습(Transfer Learning)
5. **추천 시스템(Collaborative Filtering)**: 영화 평점 예측 알고리즘 구현
6. **디퓨전 모델과 최신 생성형 AI**: 안정적 확산(Stable Diffusion)의 수학적 직관
