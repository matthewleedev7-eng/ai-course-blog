## 📌 어떤 강의인가요?
**OpenAI Academy**는 ChatGPT 개발사인 OpenAI가 직접 운영하는 교육 이니셔티브로, 입문자부터 개발자까지 누구나 최신 AI 기술을 안전하고 효과적으로 활용할 수 있도록 돕는 무료 교육 플랫폼입니다.

단순히 챗봇을 사용하는 방법을 넘어, **OpenAI API 연동, 함수 호출(Function Calling), 프롬프트 최적화 기법, 시스템 아키텍처 설계**까지 최신 업데이트 사항이 가장 빠르게 반영되는 곳입니다.

---

## 🎯 추천 대상
- ChatGPT를 업무나 코딩에 200% 활용하고 싶은 비전공자 및 개발자
- OpenAI API(GPT-4o, o1/o3 등)를 내 서비스나 앱에 직접 연동하고 싶은 개발자
- 공식 프롬프트 엔지니어링 모범 사례(Best Practices)를 체계적으로 배우고 싶은 분

---

## 📚 주요 커리큘럼 및 학습 내용
1. **생성형 AI 기초 원리**: 토큰(Token), 컨텍스트 윈도우, 모델의 작동 메커니즘
2. **프롬프트 디자인 핵심 패턴**: 역할을 부여하고 출력 포맷(JSON 등)을 강제하는 명확한 지시법
3. **OpenAI API 시작하기**: API 키 발급부터 Python/Node.js SDK를 활용한 호출 기초
4. **고급 기능 실습**: Tools/Function Calling, Assistants API, 벡터 검색 기반 RAG 기초
5. **안전성 및 가드레일**: 환각(Hallucination) 완화 전략과 윤리적 AI 사용 가이드

## 💡 수강 팁 & 활용 팁
- **크롬 자동 번역 기능 활용**: 영문 페이지이지만 크롬 브라우저 우클릭 후 '한국어로 번역'을 켜면 코드 블록을 제외한 모든 설명이 매우 자연스러운 한국어로 번역됩니다.
- **Playground 실습 병행**: OpenAI 플랫폼의 [Playground](https://platform.openai.com/playground)를 함께 띄워두고 파라미터(Temperature, Top P 등)를 직접 조정해가며 결과를 비교해보면 이해도가 훨씬 높아집니다.
- **비용 0원으로 시작**: 튜토리얼 문서와 가이드는 완전 무료로 열람 가능합니다.
