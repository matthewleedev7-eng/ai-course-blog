## 📌 어떤 강의인가요?
**구글 머신러닝 집중과정(Machine Learning Crash Course, MLCC)**은 구글 본사 연구진과 엔지니어들이 사내 소프트웨어 엔지니어들을 인공지능 전문가로 육성하기 위해 직접 설계했던 전설적인 내부 교육 과정을 전 세계에 100% 무료로 개방한 공식 코스입니다.

어려운 편미분이나 고난도 선형대수학 수식을 손으로 푸는 대신, **브라우저에서 직접 슬라이더를 조작하며 신경망이 오차를 줄여가는 과정을 시각적으로 체험하는 TensorFlow Playground**와, 1클릭으로 실행되는 **Google Colab 실습 노트북**을 통해 머신러닝의 뼈대를 가장 직관적이고 확실하게 체득할 수 있습니다.

모든 강의 영상과 실습 자료, 인터랙티브 퀴즈가 **한국어로 완벽하게 번역**되어 있어 국내 학습자에게도 진입장벽이 매우 낮습니다.

## 🎯 이런 분들께 추천합니다
- 머신러닝/딥러닝의 작동 원리를 수식 부담 없이 시각적이고 직관적으로 이해하고 싶은 초중급 학습자.
- 파이썬 기본 문법은 알지만 인공지능 모델 학습(경사하강법, 과적합, 손실 함수 등)의 핵심 메커니즘을 제대로 잡고 싶은 개발자.
- 구글 본사 엔지니어들이 실제 현업에서 AI 모델을 디버깅하고 데이터 품질을 평가하는 실전 노하우를 배우고 싶은 분.

## 📚 핵심 커리큘럼
1. **머신러닝 기초 개념**: 지도학습, 선형 회귀, 손실(Loss) 함수 및 경사하강법의 시각적 이해
2. **모델 학습 최적화**: 학습률(Learning Rate), 과적합(Overfitting), 훈련 세트와 테스트 세트의 분리
3. **분류와 로지스틱 회귀**: 참/거짓 판정, 정밀도(Precision)와 재현율(Recall), ROC-AUC 곡선 해석
4. **신경망(Neural Networks) 구조**: 비선형성 도입, 은닉층(Hidden Layers), 역전파의 기본 메커니즘
5. **임베딩(Embeddings)과 추천 시스템**: 고차원 범주형 데이터를 저차원 밀집 벡터로 압축하는 원리
6. **실전 머신러닝 엔지니어링**: 데이터 수집 편향 방지, 공정성(Fairness), 프로덕션 배포 체크리스트
