## 📌 어떤 강의인가요?
전 세계 클라우드 시장 점유율 1위 기업인 **아마존 웹서비스(Amazon Web Services, AWS)**가 클라우드 소프트웨어 엔지니어와 솔루션 아키텍트를 위해 제작한 **공식 생성형 AI 전문 개발자 러닝 플랜(Generative AI Learning Plan for Developers)**입니다.

AWS 공식 교육 포털인 **AWS Skill Builder**를 통해 100% 무료로 제공되며, 생성형 AI의 핵심 개념부터 시작하여 **AWS Bedrock을 활용한 엔터프라이즈급 파운데이션 모델(Claude, Llama, Titan 등) API 연동, LangChain 결합, 검색 증강 생성(RAG) 파이프라인 구축, 그리고 책임 있는 AI 보안 거버넌스**까지 실무에서 즉시 활용할 수 있는 클라우드 AI 아키텍처를 가르칩니다.

모든 코스는 비디오 강의, 대화형 퀴즈, 실습 아키텍처 다이어그램으로 구성되어 있으며, 전 과정을 완료하면 **공식 디지털 배지(Badge)**를 획득할 수 있습니다.

---

## 🎯 추천 대상
- 클라우드 인프라(AWS) 환경에서 생성형 AI 기반 상용 엔터프라이즈 서비스를 직접 설계/배포하고 싶은 백엔드 개발자
- 단일 LLM 호출을 넘어, 사내 문서 데이터를 안전하게 결합하는 RAG(검색 증강 생성) 아키텍처를 체계적으로 배우고 싶은 엔지니어
- AWS 공식 교육 수료 기록과 공인 디지털 배지를 취득하여 이력서와 링크드인(LinkedIn) 스펙을 강화하고 싶은 분

## 📚 주요 커리큘럼 구성
1. **Introduction to Generative AI - Art of the Possible**: 생성형 AI의 기초 개념, 비즈니스 유스케이스, 파운데이션 모델 개요
2. **Planning a Generative AI Project**: 프로젝트 타당성 검토, 비용 최적화 전략, 위험 평가 및 모델 선택 기준
3. **Amazon Bedrock Getting Started**: 단일 API로 Claude 3.5, Llama 3, Amazon Titan 등 멀티 모델을 안전하게 호출하는 방법
4. **Prompt Engineering Basics in Bedrock**: 클라우드 콘솔 환경에서의 효율적인 시스템 프롬프트 엔지니어링 및 토큰 최적화
5. **Building Generative AI Applications with LangChain**: LangChain과 Amazon Bedrock을 결합한 에이전트 워크플로우 구성
6. **Retrieval Augmented Generation (RAG) on AWS**: Amazon OpenSearch Service 및 벡터 데이터베이스를 활용한 실전 RAG 구현
7. **Security, Privacy, and Responsible AI**: 데이터 폐쇄망 유지, 가드레일(Guardrails for Amazon Bedrock)을 통한 유해 응답 필터링
