## 📌 어떤 강의인가요?
전 세계 오픈소스 AI 생태계의 중심지 **허깅페이스(Hugging Face)** 엔지니어링 팀이 직접 집필하고 유지 관리하는 **공식 자연어 처리(NLP) 코스**입니다.

단순히 `pipeline()` 함수 한 줄 호출하는 법을 넘어, **BPE(Byte-Pair Encoding) 토크나이저의 내부 수학적 원리, 사전학습 모델 가중치 로드, PyTorch 기반 커스텀 데이터셋 파인튜닝, 평가 지표 산출, 그리고 Hugging Face Hub에 모델을 배포하고 데모(Spaces)를 띄우는 전 과정**을 손으로 직접 구현합니다.

모든 장(Chapter)마다 Google Colab에서 1클릭으로 바로 실행할 수 있는 실습 코드가 무료로 제공됩니다.

## 🎯 이런 분들께 추천합니다
- Hugging Face의 `transformers`, `datasets`, `tokenizers`, `accelerate` 라이브러리를 제대로 마스터하고 싶은 개발자.
- 기업 내부 데이터셋으로 BERT, RoBERTa, Llama 모델을 커스텀 파인튜닝(Fine-tuning)하려는 엔지니어.
- 오픈소스 LLM을 내 서버에 직접 로드하고 서빙하는 백엔드 파이프라인을 구축하고 싶은 분.

## 📚 핵심 커리큘럼
1. **Transformer 모델 소개**: 어텐션(Attention) 메커니즘과 인코더/디코더 아키텍처
2. **Transformers 라이브러리 사용법**: 모델과 토크나이저의 입출력 텐서 완벽 이해
3. **사전학습 모델 미세조정 (Fine-tuning)**: PyTorch 및 Trainer API를 활용한 문서 분류기 학습
4. **Hugging Face Hub 공유**: 훈련된 가중치 업로드 및 모델 카드 작성
5. **다양한 NLP 태스크 실전**: 개체명 인식(NER), 번역, 질문 답변(QA), 요약 모델 구축
6. **고성능 토크나이저 심층 학습**: 밑바닥부터 만드는 토크나이저 트레이닝
7. **실제 서비스 배포 & 경량화**: Gradio 기반 웹 데모 제작 및 양자화(Quantization)
