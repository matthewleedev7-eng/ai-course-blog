## 📌 어떤 강의인가요?
데이터 사이언티스트들의 성지인 **Kaggle(캐글)**에서 제공하는 **'Intro to Machine Learning'** 무료 단기 코스입니다.

방대한 이론 대신, 실제 부동산 가격 예측 데이터를 가지고 **의사결정나무(Decision Tree), 랜덤 포레스트(Random Forest)** 모델을 3시간 만에 직접 구축하고 모델의 성능을 평가(Validation)하는 실전 위주 코스입니다. 모든 챕터 실습을 마치면 즉시 **공식 디지털 수료증(Certificate)**을 발급받을 수 있습니다.

---

## 🎯 추천 대상
- 파이썬 기본 문법은 알지만 머신러닝 모델을 어떻게 시작해야 할지 막막한 분
- 이론보다는 실제 코드(Scikit-Learn)를 작성하며 빠르게 머신러닝 감을 잡고 싶은 분
- 캐글 컴페티션(Competition)에 참가하기 위한 가장 첫 단계를 밟고 싶은 분

---

## 📚 주요 커리큘럼
1. **머신러닝 모델의 기본 원리**: 데이터에서 패턴을 학습하는 방식
2. **첫 모델 만들기**: Scikit-learn 라이브러리로 DecisionTreeRegressor 구현
3. **모델 검증(Validation)**: MAE(평균 절대 오차)를 통한 과적합(Overfitting) 방지
4. **언더피팅과 오버피팅 다루기**: 최적의 트리 깊이 찾기
5. **랜덤 포레스트(Random Forest)**: 여러 개의 트리를 묶어 예측 정확도 극대화하기
6. **최종 머신러닝 컴페티션 제출**: 내가 만든 예측 결과를 캐글에 직접 제출해 등수 확인
