## 📌 어떤 강의인가요?
구글 클라우드의 공식 교육 플랫폼인 **Google Cloud Skills Boost**에서 엔지니어 및 기술 기획자를 위해 제공하는 **Vertex AI & Generative AI for Developers 공인 실전 트랙**입니다.

단순히 이론만 듣는 것이 아니라, **구글 클라우드가 제공하는 무료 샌드박스 가상 환경에 접속하여 실제 기업용 콘솔인 Vertex AI Studio를 직접 조작**합니다. 최신 **Gemini 1.5 Pro / Flash 모델을 API로 호출하고, 파이썬 SDK로 멀티모달 프롬프트를 설계하며, 기업 내부 문서를 벡터 검색 데이터베이스(Vector Search)에 연결하는 검색 증강 생성(RAG) 파이프라인**을 손으로 구축합니다.

과정 내 모든 실습 랩(Lab)과 챌린지를 완료하면 링크드인(LinkedIn)과 이력서에 영구 인증할 수 있는 **구글 클라우드 공식 디지털 스킬 배지(Skill Badge)**가 발급됩니다.

---

## 🎯 이런 분들께 추천합니다
- 구글 클라우드의 인프라 위에서 실제 작동하는 엔터프라이즈 생성형 AI 서비스를 구축하고 싶은 개발자.
- 기업 내부 데이터를 안전하게 연동하는 RAG(검색 증강 생성)와 벡터 검색의 실무 아키텍처를 배우고 싶은 엔지니어.
- 이력서 및 포트폴리오에 등록할 수 있는 구글 공인 기술 인증 배지가 필요한 취업 준비생 및 클라우드 실무자.

---

## 📚 핵심 커리큘럼
1. **Vertex AI Studio 입문**: 콘솔 UI를 활용한 Gemini 모델의 제로샷(Zero-shot) / 퓨샷(Few-shot) 프롬프트 튜닝
2. **Python SDK 기반 모델 제어**: 파이썬 코드로 텍스트, 이미지, 비디오, 오디오를 처리하는 멀티모달 API 호출
3. **구조화된 출력 및 Function Calling**: JSON Schema 강제 출력과 외부 API 도구 연동(Tool-use)
4. **Vertex AI Vector Search & RAG**: 대규모 문서를 텍스트 임베딩으로 변환하고 벡터 인덱스를 구축하여 RAG 챗봇 완성
5. **책임감 있는 AI 안전성 필터**: 폭력성, 혐오 표현을 차단하는 안전성 속성(Safety Settings) 커스터마이징
6. **최종 챌린지 랩 및 구글 공인 배지 발급**: 제한 시간 내 실무 과제를 해결하고 공인 디지털 수료 배지 획득
