## 📌 어떤 강의인가요?
코세라(Coursera) 창립자이자 스탠퍼드 겸임교수인 **앤드류 응(Andrew Ng)** 박사와 OpenAI의 기술 스태프인 **Isa Fulford**가 직접 강의하는 전설적인 무료 단기 코스입니다.

일반적인 "챗GPT 잘 쓰는 법" 수준을 넘어, **LLM API를 프로그래밍 코드(Python) 내에서 조작하여 요약, 추론, 변환, 확장을 자동화하는 2대 핵심 프롬프트 원칙**을 1시간 반 만에 명쾌하게 가르쳐 줍니다.

## 🎯 추천 대상
- 주먹구구식 프롬프트 작성을 벗어나 체계적인 프롬프트 작성 공식(Delimiters, Few-shot 등)을 익히고 싶은 분
- 파이썬 기초 지식이 있으며, 내 코드에서 OpenAI API를 호출해보고 싶은 입문자
- 브라우저만으로 별도 개발 환경 설치 없이 주피터 노트북 실습을 바로 해보고 싶은 분

## 📚 주요 커리큘럼 및 학습 내용
1. **프롬프트 가이드라인의 2대 원칙**:
   - 원칙 1: 명확하고 구체적인 지시 작성하기 (구분 기호 활용, 구조화된 출력 요구, 조건 확인 등)
   - 원칙 2: 모델에게 "생각할 시간" 주기 (단계별 풀이 유도, 성급한 결론 방지)
2. **반복적 프롬프트 개선(Iterative Prompt Development)**: 의도한 결과가 나올 때까지 오류를 디버깅하는 방법
3. **핵심 활용 4대 패턴**:
   - **Summarizing**: 장문의 글/리뷰 핵심 요약
   - **Inferring**: 감성 분석, 토픽 추출
   - **Transforming**: 번역, 맞춤법 교정, 톤 변경, 포맷 변환(HTML, JSON)
   - **Expanding**: 고객 이메일 자동 맞춤 회신 생성
4. **나만의 챗봇(Chatbot) 만들기**: 시스템 프롬프트(System Message)와 대화 히스토리 메모리 구현
