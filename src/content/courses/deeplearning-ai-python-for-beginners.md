## 📌 어떤 강의인가요?
머신러닝의 세계적 석학 **앤드류 응(Andrew Ng) 교수**가 이끄는 **DeepLearning.AI**가 비전공자와 프로그래밍 입문자를 위해 새롭게 선보인 **"모두를 위한 AI 파이썬 (AI Python for Beginners)"** 공식 코스입니다.

기존의 지루한 문법 암기식 코딩 교육과 완전히 다릅니다. 설치 과정 없이 브라우저에서 바로 실행되는 대화형 주피터 노트북(Jupyter Notebook) 환경에서, **변수와 반복문 기초부터 시작하여 챗봇 API 호출, 텍스트 요약, 데이터 전처리, 업무 자동화 툴 제작까지 AI를 활용하여 파이썬을 학습**하도록 설계되었습니다.

- 앤드류 응 교수의 명쾌하고 쉬운 설명으로 프로그래밍의 핵심 원리를 잡고 싶은 입문자.
- 복잡한 로컬 개발 환경 세팅(VS Code, 가상환경 등) 없이 브라우저에서 1초 만에 코딩 실습을 하고 싶은 분.

## 📚 핵심 커리큘럼
1. **AI와 함께하는 파이썬 첫걸음**: 변수, 데이터 타입, 함수 개념을 프롬프트와 함께 이해하기
2. **반복문과 제어 흐름**: 조건문과 루프를 활용한 대화형 프로그램 로직 구성
3. **리스트와 딕셔너리**: 복잡한 비정형 텍스트 및 JSON 데이터 다루기
4. **LLM API 연동 실전**: 파이썬 코드로 OpenAI / Anthropic 모델에 프롬프트 전달 및 응답 파싱
5. **실무 자동화 미니 프로젝트**: 긴 보고서 자동 요약 및 데이터 분류 스크립트 완성
