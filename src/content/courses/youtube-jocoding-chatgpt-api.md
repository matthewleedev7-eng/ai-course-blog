## 📌 어떤 강의인가요?
국내에서 가장 많은 비전공자를 코딩과 AI의 세계로 이끈 **유튜버 조코딩(JoCoding)**의 대표 무료 실전 코스입니다.

어려운 문법 강의를 수십 시간 듣지 않고도, **HTML/CSS/JS 기초와 파이썬, 그리고 OpenAI의 ChatGPT API를 조합하여 실제로 방문자가 사용할 수 있는 AI 웹 서비스(운세, 글 작성기, 이미지 생성기 등)를 하루 만에 직접 만들고 인터넷에 배포**하는 과정을 압축하여 보여줍니다.

---

## 🎯 추천 대상
- 코딩을 1초도 안 해봤지만 내 이름으로 된 AI 웹사이트를 인터넷에 띄워보고 싶은 완전 초보자
- OpenAI API 키를 발급받았는데 어떻게 활용해야 할지 구체적인 예제가 필요한 분
- 완성된 웹사이트에 구글 애드센스 광고나 카카오 애드핏을 달아 소소한 커피값 수익을 만들어보고 싶은 분

---

## 📚 주요 커리큘럼 구성
1. **웹의 기초 동작 원리**: 프론트엔드와 백엔드가 데이터를 주고받는 방식
2. **OpenAI API 가입 및 키 발급**: 요금 체계 이해와 API 키 안전하게 관리하기
3. **나만의 AI 웹페이지 UI 꾸미기**: 부트스트랩(Bootstrap)과 Tailwind로 깔끔한 디자인 입히기
4. **API 통신 연결**: 사용자가 질문을 입력하면 GPT 모델이 답변하도록 스크립트 작성
5. **무료 웹 호스팅 배포**: Netlify / GitHub Pages를 통한 전 세계 무료 호스팅 연결
6. **구글 애드센스 광고 달기**: 완성된 사이트에 광고 코드를 삽입하고 수익화하는 방법

---

## 💡 수강 팁 & 활용 팁
- **완성 소스 코드 제공**: 영상 설명란의 깃허브 링크에서 완성된 소스 코드를 그대로 다운로드받을 수 있어, 오타 때문에 막힐 걱정 없이 학습할 수 있습니다.
- **포트폴리오 응용**: 영상에서 만드는 예제를 조금만 아이디어를 변형하면(예: 여행 일정 플래너, 면접 질문 생성기 등) 나만의 훌륭한 첫 AI 포트폴리오가 됩니다.
